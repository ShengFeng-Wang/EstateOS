# ESTATE / OS Specification Index

ESTATE / OS is a portfolio-scale internal property asset management platform. It demonstrates full-stack product engineering, data relationships, responsive React UI, and a data-driven interactive Three.js digital twin.

## Approved direction

- Product scope: Balanced Portfolio MVP
- Audience: internal asset management company staff
- Asset scale: 50–200 residential and commercial properties
- UI language: English primary, Traditional Chinese localization
- Responsive scope: all screens on desktop; core flows on tablet and mobile
- Visual direction: Architectural Intelligence × Spatial Signal
- Three.js direction: concrete Digital Twin City with complete interaction
- Expected Figma scope: approximately 165–190 product frames and specification boards

## Authority order

When documents appear to conflict, use this order:

1. Product specification and approved exclusions
2. Acceptance criteria
3. Design system
4. Screen and component specifications
5. Three.js, responsive, and localization specifications
6. Implementation brief

Unresolved material decisions must be recorded in `docs/handoff/questions-for-codex.md`. Claude Code must not silently redesign the product.
